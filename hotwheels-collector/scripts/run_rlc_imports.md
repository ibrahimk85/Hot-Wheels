# Red Line Club (RLC) Import Scriptleri

Her yıl için önce veri import scripti, sonra resim download scripti çalıştırılmalıdır.

## 2017 Yılı

### 1. Veri Import
```bash
npx ts-node scripts/import/import_rlc_2017.ts
```

### 2. Resim İndirme
```bash
npx ts-node scripts/tools/download_and_sync_images_rlc_2017.ts
```

## Notlar

- Her yıl için önce veri import scripti çalıştırılmalıdır
- Veri import tamamlandıktan sonra resim download scripti çalıştırılmalıdır
- Scriptler veritabanında mevcut kayıtları güncelleyecek, yeni kayıtlar ekleyecektir
- Çoklu çalıştırmalar güvenlidir (idempotent)
